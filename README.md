# overseas-news-digest

海外资讯的公开来源短摘要。只收录打开原始页面后能够核对标题、发布时间和摘要事实的条目。

## 审核

- 路径日期用采集当天的北京时间（Asia/Shanghai，UTC+8），格式为 `YYYY/MM/DD/版块/slug.md`。
- 版块只使用：科技、搞笑、财经、娱乐、体育、社会、健康、其他。没有通过审核的版块不补空文。
- 来源页面必须能公开打开。打不开、付费墙后无法核对、超出采集时点近 48 小时、事实对不上或存在争议的，不收录。
- 不收录色情、暴力、血腥、宗教及擦边内容。健康条目不写血腥细节、不配图片，不把早期结果写成已确认疗效，并写明临床阶段。体育只写比分和公开技术统计，不写受伤情节。
- 来源只给出日期时，时间只保留日期，不补时区或钟点。来源给出钟点的，按原始时区换算为上海时间。
- 不上传图片、视频、全文转载、个人隐私或未经审核的素材。

## 单篇格式

每篇包含中文标题、版块、来源、来源标题、来源链接、原始发布时间、上海时间，以及一两段中文摘要。
