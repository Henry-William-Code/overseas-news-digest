### 重点 · ChatGPT Enterprise 进入 AWS Marketplace

OpenAI 在 11 月 9 日的公告里说，ChatGPT Enterprise 已可从 AWS Marketplace 购买。机构可以用现有的 AWS 采购和账单关系下单，符合条件的花费可以计入 AWS 承诺额。公告写明，这里的模型和功能与直接向 OpenAI 购买的相同，新功能同时放出。

<a id="control-room"></a>

### OpenAI 在研究环境部署 Control Room，用来叫停模型任务

OpenAI 介绍了已经部署在研究基础设施上的 Control Room。它给研究推理任务编号，推理引擎在每次生成前向它确认任务是否仍被允许。一旦标记停止，引擎拒绝继续输出。公司称，从收到停止指令到不能再往下生成，最长约 35 秒，延迟来自授权缓存。

系统按“失败即关闭”设计：Control Room 本身中断时，前沿研究任务的推理请求会被拒绝。这一设置已用于前沿研究，其余研究任务计划在随后几天补齐。对外模型服务不在这套新系统里，OpenAI 说那一侧本来就能较快下线。

### Claude Code 的“不再询问”可能把密钥写进后来被公开的设置文件

Ars Technica 报道，安全公司 Apiiro 在公开 GitHub 仓库的 Claude Code 设置文件里发现了数以千计的密钥，包括数据库密码、API 令牌和 root 登录信息。触发点是用户批准自动执行命令时选择不再询问。这个选择会写成本地设置文件里的规则，命令原文有时连同其中的敏感内容一起被保存。

Anthropic 的文档说，该设置文件会被加入全局 gitignore。Ars 写明，这不等于仓库级别一定忽略它。Apiiro 还称，不少情况下工具会在用户没有另行确认时提交这个文件。文件留在本机时风险有限；一旦进入公开仓库，密钥就暴露了。

发布：上海时间2026-11-10 01:24｜[Ars Technica](https://arstechnica.com/ai/2026/11/claude-code-settings-files-expose-thousands-of-secrets-on-github/)

### 重点 · 僵人综合征的 CAR-T 试验出现早期改善，尚不知能否维持

《卫报》报道，美国医生在试验一种用于僵人综合征的免疫治疗。这种罕见自身免疫病目前没有治愈方法。梅奥诊所使用已在癌症中用过的 CAR-T：取出患者自己的 T 细胞，改造后再输回。结果发表在《JAMA Neurology》。

报道称，一些原先行走和日常事务需要帮助的人，重新能够工作或恢复兴趣爱好。梅奥的 Anastasia Zekeridou 说，这是早期结果，关键是改善能否持续。文章没有给出试验人数，也没有说这种用法已经获批。报道没有说席琳·迪翁接受了该治疗。

发布：上海时间2026-11-10 00:42｜[The Guardian](https://www.theguardian.com/science/2026/nov/09/medical-breakthrough-offers-hope-to-people-with-same-stiff-person-syndrome-as-celine-dion)
