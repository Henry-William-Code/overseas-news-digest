## 摘要

GitHub 宣布，Google 的 Gemini 4 Carbon 已在 GitHub Copilot 中一般可用，面向 Copilot Pro+、Max、Business 和 Enterprise 用户，适用于复杂编程、代理式任务和推理，并强调安全代码生成相关场景。该模型按提供方目录价计入按量计费。

可在 VS Code、Visual Studio、Copilot CLI、coding agent、GitHub Copilot 应用、github.com、GitHub Mobile、JetBrains、Xcode 和 Eclipse 的模型选择器中选用。官方称将逐步推送。Copilot Enterprise 与 Business 管理员可通过模型策略管理访问；在默认启用新模型的设置下，除非管理员关闭全局默认或单独关闭该模型，否则新模型会自动开启。这是 GitHub 产品侧的接入，有别于早间 Google 宣布 Carbon 可供开发者使用。
