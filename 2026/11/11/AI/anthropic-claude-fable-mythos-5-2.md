## 摘要

Anthropic 宣布推出 Claude Fable 5.2，并同步推出面向受审核机构的 Claude Mythos 5.2。公司称两者是同一底层模型：Fable 带有更强的网络安全与生物学防护，向所有用户开放；在网络安全或生物医学研究中有正当用途的机构，可通过已扩大的生命科学与网络验证计划申请 Mythos。官方建议大多数编程与知识工作仍先使用 Claude Opus 5.5，只在任务足够难时再换到 Fable 或 Mythos。

公司称，相比 5.1，新模型在编程、推理和视觉等方面有提升，生成速度最高约快 30%，定价为每百万输入 token 8 美元、每百万输出 token 40 美元；可选 Fast mode，官方称最高可将 token 生成加快约 2.5 倍，价格为 16 / 80 美元。Fable 5.2 已在 Anthropic 自有平台以及 Amazon Web Services、Google Cloud、Microsoft Azure 上线，开发者模型名为 `claude-fable-5-2`。文中列举的正式化费马大定理、硬件原型和蛋白质壳体结构预测等结果，均属公司自身陈述，尚未见独立复现。

为何关注：这是早间已报道的 Claude 表格/白板之外，Anthropic 在同一时段的主力高阶模型更新，也会影响 Claude Code 及云厂商上的模型选择。
