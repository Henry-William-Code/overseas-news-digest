## 摘要

微软宣布，Automatic Super Resolution（Auto SR）已在 ROG Xbox Ally X 和 ROG Xbox Ally X20 上结束预览、正式推出，并扩展到部分搭载 AMD Ryzen 的 Windows Copilot+ PC。预览阶段只能在接底座时使用，且游戏往往需要先降低分辨率；正式版已支持掌机未接底座、依靠电池在内置屏幕上游玩，也可直接用于以 1080p 运行的游戏。接上更高分辨率电视或显示器时，官方称最高可放大到 1440p。

新的 Performance Mode 将帧率上限从此前约 60–75 FPS 提高到最高 120 FPS，并可与 Auto HDR 同时使用；这两项将随 Windows 更新陆续推送，可能不会马上到达所有设备。微软同时提醒：在内置屏幕以 1080p 使用时，性能未必像其他配置那样理想，但仍可能改善画质，尤其是较老的游戏。用户需更新 Game Bar 和 Windows 11，并从 Microsoft Store 安装或更新 Auto Super Resolution 包。
